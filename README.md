# Albverein Schwenningen/Heuberg

Installierbarer Web-App-Prototyp für die Ortsgruppe Schwenningen/Heuberg des Schwäbischen Albvereins.

## Enthalten

- Termine und Wanderplan
- Meldungen und Push-Demonstration
- Vorstand und Bildergalerie
- Formulare für Änderungsmitteilungen
- Demo-Adminbereich mit individuell einstellbaren Rechten für Admin 1, 2 und 3
- PWA-Manifest und Service Worker für die Installation auf iPhone und Android

## Wichtiger Hinweis

Dies ist derzeit ein klickbarer Prototyp. Anmeldung, Formulare, E-Mail-Benachrichtigungen und Datenspeicherung sind noch nicht mit einem sicheren Server verbunden. Es werden keine Passwörter oder Bankdaten im GitHub-Repository gespeichert.

Die veröffentlichte Web-App wird aus dem Inhalt des Ordners `dist` erzeugt.
